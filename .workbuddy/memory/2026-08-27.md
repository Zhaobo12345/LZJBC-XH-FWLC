## 修复「项目列表及详情主页-新」点击切换无反应
- 现象：点"切换"面板不出现。
- 根因：`.proj-panel`（下拉面板）原为 `.topbar` 的**兄弟节点**，其 CSS `position:absolute; top:100%` 相对最近定位祖先 `.phone-frame`（高 812px）定位，导致面板被推到手机框底缘之外、被 `overflow:hidden` 裁掉而不可见。
- 修复：将 `#projPanel` 移入 `.topbar` 内部（作为子节点），使 `top:100%` 相对切换条定位，展开即紧贴切换条下方覆盖详情区；并新增 `document` 点击监听——点击面板外（详情区等）自动收起面板。
- 现状：切换/角色切换/层级/更多/接单校验均正常。
